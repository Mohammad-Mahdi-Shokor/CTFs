The following commands are commands that could help you in foresincs ctfs and could be used on files ( in linux ) 
Note: you may need to install some of them cause not all of them are preinstalled 

exiftool : show description / author / ...  of a file
binwalk -e: extract hidden data / files
steghide : extract hidden data with passphrase ( not like binwalk !!) 
stegseek
eog : view image
strings : shows strings inside the file , skips gibrish
xxd : shows the whole hexadecimal of the file
hexeditor : edits the head of hex of a file
zsteg : it helps in LSB
java -jar bin/stegsolve.jar  : opens stegsolve which shows picture under different color schemes 
zbarimg : scans qr code and shows output
unzip: unzips files ( use -l to list all files in it ) 
zipinfo: gives you info about zip file
wireshark : capture network traffic + view pcap files with better view than terminal
stegolsb steglsb -r -i secret.png -n 2 -o secret_output ( now flag is hidden in secret_outpt) : extracts lsb hidden files
stegsuite: extract hidden files using password : stegosuite extract -k "password" file.jpg
- there is also stegsuite.java (has better ui but slow) : https://github.com/osde8info/stegosuite
