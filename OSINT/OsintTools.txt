Tools mentioned in ctf training :
1. nmap <IP/link> : to scan for available ports ( initially only TCP ports )
2. arp-scan <Your IP>/<prefix length> : Scans available IPs in specific range (2 to the power of (32 - prefix length ) )
3. (website) nslookup.io : view dns records of a website ( their IPs / records / Google DNS data / ... ) 
4. dig TXT <IP/link> : view DNS records in kali
5. gobuster dns --domain <link> --wordlist wordlist.txt : check what subdomains from a wordlist the website is using
6. cewl <https://link/> : used to find common words in a website and save them using -w wordlist.txt to a file (may use them in bruteforce / subdomain enumeratio/...)
7. subfinder <IP/link> : finds subdomains 
8. dq : add it at the end of command that reads json , it makes it readable
