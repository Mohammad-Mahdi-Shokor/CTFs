Here is a list of tools I used for web CTFs:

- Burpsuite : track , view & modify requests running through the website
- Wireshark : track network packets
- subfinder : finds subdomains
- nmap : finds hidden ports
- paramspider : finds hidden endpoints
- nuclei : finds vulnerabilities in websites
- telnet :  to test and troubleshoot network services by establishing a raw, unencrypted TCP connection to a remote host on a specific port
